# internal/config

В этом пакете хранятся конфигурации приложения.

Загрузку конфигурации можно реализовать из различных источников, например: файлов, переменных окружения, баз данных и других.

## Аудит запросов

- `--audit-file` / `AUDIT_FILE` — путь к файлу аудита. События добавляются в конец файла в формате JSON Lines.
- `--audit-url` / `AUDIT_URL` — полный HTTP(S) URL приёмника. Каждое событие отправляется отдельным POST с `Content-Type: application/json`.

Непустые переменные окружения имеют приоритет над флагами. Каждый приёмник включается независимо; без соответствующей настройки он отключён.

Пример запуска с обоими приёмниками:

```sh
go run ./cmd/shortener --audit-file=./audit.jsonl --audit-url=http://localhost:9090/audit
```

После успешного `POST /` или `POST /api/shorten` создаётся событие `shorten`, после успешного `GET /{id}` — `follow`. Поле `url` содержит оригинальный URL, `ts` — Unix timestamp в секундах, `user_id` — идентификатор пользователя из контекста запроса (при отсутствии пользователя поле опускается). Ошибки запросов, включая повторное сокращение с ответом 409, не создают событий.

Издатель уведомляет всех зарегистрированных наблюдателей синхронно. Ошибки доставки записываются в журнал сервера и не меняют ответ клиенту; другие приёмники всё равно получают событие. Таймаут HTTP-доставки — 5 секунд, повторные отправки не выполняются.
